# Code-Scrapbook

A personal collection of small programs, experiments, demos, and code snippets in different languages.

## Projects

- [Ray casting](projects/ray-casting/) draws a first-person view of a 2D map using Pygame. Its dependencies are in `requirements.txt`.
- [L-systems](projects/l-systems/) visualizes Lindenmayer systems with Python's `turtle` module.
- [`wc`](projects/wc/) is a C exercise in counting lines, words, and bytes on Unix.
- [Saper](projects/saper/saper.py) is a terminal Minesweeper game in Python that uses Colorama.

## Experiments

- [Collatz conjecture](experiments/collatz-conjecture/) explores the Collatz sequence in C#.
- [Birthday problem](experiments/birthday-problem/) explores shared birthdays in a Jupyter notebook.
- [IEEE 754](experiments/ieee-754/) contains two Python and NumPy experiments with floating-point representations.

## Demos

- [Hello, world](demos/hello-worlds/) collects examples in eleven languages.
- [Hello, world on 32-bit x86](demos/hello-world-x86-32/) uses NASM and a Linux ELF executable.
- [Python type hints](demos/type-hinting/) illustrates annotations, generics, and typing helpers.
- [Python debugger](demos/python-debugger/) pairs a small debugger with an example script.
- [Rainbow spiral](demos/rainbow-spiral.py) draws a spiral with Python's `turtle` module.

## Snippets

[Short examples](snippets/) include Python versions of familiar C and C++ idioms, a C matrix-power routine, a signal demonstration, and a [custom text cipher](snippets/vi.py).
